# Security policy

## Current status

NoobCoin is an experimental community-token project. The smart contract has not undergone an independent professional security audit and is not represented as production-ready.

## Reporting a vulnerability

Do not publish exploit details or private information in a public issue. Use a private security advisory through the repository Security tab if available.

## Never disclose

- Secret Recovery Phrases / seed phrases
- Wallet private keys
- Wallet passwords
- API keys, access tokens, or other credentials
- Unredacted .env files

The maintainers will never need your wallet recovery phrase or private key to investigate a report.
